# BULK SHARE — Requirements Traceability Matrix

## Milestone 1 Traceability
- **FR-AUTH-01:** Users sign up/in with email/password or Google (Supabase Auth).
- **FR-AUTH-02:** Backend validates JWTs, does not trust client-supplied roles.
- **FR-AUTH-03:** Local application profile linked to auth provider user ID.
- **FR-AUTH-04:** Profile management (name, neighborhood, private address).
- **FR-AUTH-05:** Role-based protected routes and views (Customer, Supplier, Admin).
- **FR-AUTH-06:** Admin privileges securely provisioned; cannot be self-assigned.
- **FR-DEMO-01:** Prominent simulation banner across public pages.
- **NFR-01 / NFR-06:** Mobile-first responsive UI, green/white grocery aesthetic.
